# CWLauncher — прогресс по 9 этапам (19.10.2026)

Проверка во всех этапах: Kotlin-компилятор 2.0.21 по всем исходникам `app/src/main/java`
(ошибок нет в изменённых файлах; остаются только ошибки окружения проверки: нет `R` и
`androidx.lifecycle`). Gradle в среде разработки не запускался. На телефоне ничего не проверялось.

## 1. Фризы и вылеты в лаунчере
- Причина (по коду): `Engine.evaluate()` (перебор и открытие всех модов в `verifyMods`, диск) и запись
  конфигов выполнялись в UI-потоке из `saveSettings`, `addOffline`, `removeAccount`, `renameOffline` и др.
  Длительность 5–7 с — наблюдение пользователя, не измерена.
- `Engine.act()`: действие идёт в фоне, один ключ = одна операция (повторный тап игнорируется), все
  действия сериализованы `Mutex`, ошибки показываются. `Engine.working` блокирует кнопки форм аккаунта и
  показывает «Выполняется…». `Accounts.items` — `CopyOnWriteArrayList` (в Compose читался во время записи).
- Файлы: `Engine.kt`, `Accounts.kt`, `Screens.kt`.

## 2. Вёрстка и новости
- Причина ложной надписи: в `NewsPage` пустой `text` у успешно загруженной новости подменялся строкой
  «Источник не ответил». Теперь `UiState.newsStatus` = loading / ok / empty / error.
- Три нижние кнопки настроек управления: отступы 10 dp и высота 48 dp (`rowLp`, `halfLp`).
- Файловый менеджер: `GhostButton(wide = false)` — компактные кнопки в `FlowRow` вместо растянутых.
- Файлы: `Engine.kt`, `Screens.kt`, `ControlsOverlay.kt`.

## 3. Редактор кнопок и клавиатура
- Кнопки: создать, удалить, переименовать, переместить, размер, прозрачность, действие. Действия: клавиша
  или сочетание (Ctrl/Alt/Shift + клавиша; буквы, цифры, F1–F12, Esc, Tab, Enter, Space, Backspace,
  стрелки, Num-клавиши и др.), кнопки мыши, колесо, приседание, спринт, чат, ПК-клавиатура, джойстик хотбара.
- Миграция: старый `controls.json` (version 1) читается без потерь, новые поля берут значения по умолчанию.
- ПК-клавиатура (EN/RU, F-клавиши, стрелки, Ctrl/Alt/Shift/Caps): посылает физический код клавиши и
  символ раскладки; кнопка по умолчанию выключена.
- Хотбар: режимы «стрелки / джойстик / оба»; тап по слоту выбирает слот (координаты считаются из
  GUI-масштаба `guiScale` и размера экрана).
- Файлы: `controls/*`, `PhoneVm.kt` (`optionInt`).

## 4. Тап и свайп в GUI
- Тап в меню = один клик в момент отпускания, курсор ставится при касании. Удержание >180 мс = нажатие
  (перетаскивание предметов). Вертикальный свайп = колесо мыши (настройка, по умолчанию включено).

## 5. Камера при удержании любой кнопки
- Палец на кнопке продолжает владеть касанием; его движение поворачивает камеру (`lookBy`), действие
  остаётся зажатым. Исключение: жест фиксации приседания (скольжение по кнопке).
- Сброс всех клавиш: ACTION_CANCEL, потеря фокуса, onPause.

## 6. Сохранение графики
- Причина: `GameLaunch.applyOptions()` при каждом запуске и при каждом сохранении настроек заново писал
  стартовые значения (`renderDistance=2`, `maxFps=10` и др.) в `options.txt`; обновление сборки модов
  перезаписывало `config/` (в том числе настройки Sodium/Iris).
- Теперь стартовый профиль пишется только при отсутствии `options.txt`, запись атомарная; конфиги
  графических модов не перезаписываются, если уже существуют.

## 7. Экран погас
- Настройка: «Сразу завершать» / «Через таймер» (1–60 мин) / «Всегда активен» (по умолчанию — активен,
  поведение прежнее). Реагирует только на ACTION_SCREEN_OFF. Таймер — `AlarmManager`, отмена при ACTION_SCREEN_ON.
- Завершение: Esc → клик «Сохранить и выйти/Отключиться» в паузе (по расчётным координатам,
  vanilla-вёрстка), через 5 с процесс завершается принудительно. Окно Minecraft закрыть
  снаружи нельзя (в JNI GLFW нет close-request).

## 8. Игра ↔ лаунчер
- `GameActivity` вынесена в отдельную задачу (`taskAffinity`), поэтому лаунчер можно показать, не
  уничтожая игру. Кнопка в игре «В лаунчер», в лаунчере — «Вернуться в игру». Java не перезапускается,
  поверхность переподключается. Android может выгрузить процесс при нехватке памяти.

## 9. Автоподключение
- Настройка `autoConnect`, по умолчанию включена: `--quickPlayMultiplayer` передаётся один раз, клиент
  подключается сам после загрузки. Выключено — обычный запуск в главное меню.

## Доработка 19.10.2026 (после первой проверки)
- Редактор: панель редактирования стоит с противоположной стороны от выбранной кнопки и не закрывает её;
  новая кнопка появляется слева, а не под панелью; доступно редактирование любой кнопки, включая свои.
- Выбор действия: один диалог — типы действий плашками и ПК-клавиатура для выбора клавиши с
  переключателями Ctrl/Alt/Shift (вместо списка по одной клавише в строку).
- Глаз и шестерёнка: перемещаются, меняют размер и прозрачность в редакторе; скрытие через глаз прячет
  все кнопки, включая шестерёнку (в редакторе видны обе).
- Логи: подробности по конкретным файлам загрузки пишутся только при режиме разработчика или подробных логах.
- Настройки: «Управление», «Автоподключение», «Экран погас» перенесены во вкладку «Игра»; в «Дополнительно»
  оставлены 3 кнопки (сброс, удалить версии игры, переустановка), «Удалить лаунчер» убрана.
