# CWLauncher 2.7.2 — готовая версия

Эта ветка содержит только готовый установочный пакет CWLauncher для Android. Исходники находятся в ветке [`main`](https://github.com/Difiw/CWLauncherAndroid/tree/main).

## Требования

- Android 8.0 или новее;
- 64-битный ARM-процессор (`arm64-v8a`);
- свободное место для приложения и файлов Minecraft;
- интернет для первоначальной загрузки игры, Fabric и сборки модов.

## Скачать и установить

1. Нажмите **Code → Download ZIP**.
2. Полностью распакуйте скачанный ZIP-архив.
3. Найдите файл `CWLauncher-2.7.2-arm64.apk`.
4. Если архив скачан на компьютере, скопируйте APK на Android-устройство.
5. Откройте APK на устройстве и разрешите установку приложений из этого источника, если Android попросит.
6. Нажмите **Установить**, затем запустите **CWLauncher** из меню приложений.

Java 17, native-библиотеки и ресурсы уже включены внутрь APK. Android Studio, JDK и самостоятельная компиляция не нужны.

> APK нельзя запустить непосредственно в Windows: это установочный пакет для Android.
