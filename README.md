Рабочая версия 2.7.2 находится в ветке [`main`](https://github.com/Difiw/CWLauncherAndroid/tree/main), а готовый APK — в [`launcher-ready`](https://github.com/Difiw/CWLauncherAndroid/tree/launcher-ready).

> Нужна готовая сборка без Android Studio? Перейдите в ветку **[launcher-ready](https://github.com/Difiw/CWLauncherAndroid/tree/launcher-ready)** и скачайте APK по инструкции в её README.

CWLauncher — Android-лаунчер Minecraft Java Edition, ориентированный на сервер Common World. Приложение загружает необходимые файлы игры и Fabric, управляет сборкой модов и запускает Java-версию Minecraft непосредственно на совместимом ARM64-устройстве. В приложение включена Java 17, поэтому отдельная установка JRE на телефон не требуется.

## Основные возможности

- офлайн-аккаунты и авторизация через Ely.by;
- загрузка и проверка файлов Minecraft, библиотек и ресурсов;
- установка Fabric Loader и сборки модов Common World;
- запуск Minecraft Java Edition на Android через встроенную Java 17;
- несколько игровых установок и управление их файлами;
- локальные и Ely.by-скины;
- экранные элементы управления, виртуальная клавиатура и редактор раскладки;
- настраиваемые темы, фоны и стили экрана загрузки;
- диагностика запуска, журналирование и экспорт файлов игры;
- сохранение процесса игры при переключении между игрой и лаунчером.

## Системные требования

### Для запуска APK

- Android 8.0 (API 26) или новее;
- 64-битный ARM-процессор (`arm64-v8a`);
- доступ в интернет для загрузки Minecraft, Fabric и файлов сборки;
- свободное место для APK, Java runtime, библиотек, ресурсов и выбранной сборки игры (рекомендуется не менее 2–4 ГБ);
- разрешение на установку приложений из неизвестных источников для используемого браузера или файлового менеджера.

Устройства x86/x86_64 и 32-битные ARM-устройства не поддерживаются. Для комфортной игры требования к памяти и производительности зависят от версии Minecraft и набора модов.

### Для сборки из исходников

- Windows, Linux или macOS;
- JDK 17 или новее;
- Android SDK Platform 35 и Android SDK Build-Tools;
- подключение к интернету для первой загрузки Gradle и зависимостей;
- Git. Android Studio необязательна: в репозитории есть Gradle Wrapper.

## Как скачать исходники

```bash
git clone https://github.com/Difiw/CWLauncherAndroid.git
cd CWLauncherAndroid
```

Для стабильной версии оставайтесь в ветке `main`. Для разработки используйте ветку `branch`:

```bash
git switch branch
```

## Как собрать проект

Укажите путь к Android SDK в переменной окружения `ANDROID_HOME` либо создайте локальный (не публикуемый в Git) файл `local.properties`:

```properties
sdk.dir=C\:\\Android\\Sdk
```

Соберите оптимизированный APK:

```powershell
# Windows
.\gradlew.bat clean assembleRelease
```

```bash
# Linux/macOS
./gradlew clean assembleRelease
```

Результат находится в `app/build/outputs/apk/release/`. Текущая release-конфигурация подписывает локальную сборку стандартным debug-ключом Android; для официальной публикации в магазине следует настроить собственный приватный release-keystore вне репозитория.

## Как запустить готовую версию

1. Откройте ветку **[launcher-ready](https://github.com/Difiw/CWLauncherAndroid/tree/launcher-ready)**.
2. Нажмите **Code → Download ZIP** и полностью распакуйте архив.
3. Скопируйте APK на совместимое Android-устройство, если архив скачан на компьютере.
4. Откройте файл `CWLauncher-2.7.2-arm64.apk`, разрешите установку из этого источника и установите приложение.
5. Запустите **CWLauncher** из меню приложений.

APK является установочным пакетом Android и не запускается непосредственно в Windows.

## Назначение веток

- `main` — проверенные исходники стабильного релиза 2.7.2;
- `branch` — разрабатываемая версия 2.7.3 с оптимизациями и изменённой загрузкой; сейчас запуск игрового контейнера не работает;
- `launcher-ready` — минимальный комплект для пользователя: готовый APK и короткая инструкция, без исходников и промежуточных файлов сборки.

## Проверка проекта

Перед публикацией релиза выполняются локальные unit-тесты, Android Lint и сборка release APK. Полноценный запуск Minecraft необходимо дополнительно проверять на физическом ARM64-устройстве, поскольку JVM, графический мост и сенсорное управление зависят от Android и оборудования.

## Безопасность и локальные данные

Репозиторий не должен содержать `local.properties`, keystore-файлы, токены, пользовательские аккаунты, логи, кэш Gradle и промежуточные результаты сборки. Не добавляйте такие файлы в коммиты. Учётные данные, создаваемые самим приложением, хранятся в приватном каталоге приложения на устройстве.
